# MicroFluent

A mini GPT language model I am building from scratch.

## About

MicroFluent is a small GPT style transformer that learns to predict the next token in a piece of text, and then writes new text one token at a time. It is meant to be small enough to train and run on a laptop.

## Getting started

Create a Python virtual environment, install the requirements, and run the training script.

Datasets go in the data folder, and checkpoints in the checkpoints folder. Git ignores both (see .gitignore), along with model weights, so the repository stays small.
