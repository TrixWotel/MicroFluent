# MicroFluent

A mini GPT language model built from scratch.

## About

MicroFluent is a small GPT style transformer that learns to predict the next token in a piece of text, and then writes new text one token at a time. It is meant to be small enough to train and run on a laptop. Its main purpose is programming, though it also features texting, tracking, visual, vision.
